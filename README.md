# 末日快遞隊：最後一哩

一款以末日快遞為主題的瀏覽器生存動作遊戲原型。移動躲避感染者、收集經驗並挑選技能，取得補給箱後擊退頭目，再送到安全屋。

## 試玩

直接用瀏覽器開啟 `index.html`。出勤前可選阿澄、小岑或阿樹，並選標準、高危、夜市或每日挑戰路線。使用 WASD 或方向鍵移動，Q 使用角色專屬能力，Space 使用震盪彈、F 使用誘餌鈴，Escape 暫停／繼續；角色會自動攻擊最近的敵人。手機可按住並拖曳、點畫面上的能力與道具按鈕或右上角暫停鈕，也能在街區尋找寶箱。每場結算可累積快遞員經驗與零件；零件能在基地購買常駐升級或製作急救包、震盪彈、誘餌鈴，進度儲存在目前瀏覽器。

## 專案結構

- `index.html`：遊戲頁面與介面結構。
- `assets/styles.css`：桌面與手機版樣式。
- `assets/game.js`：Canvas 遊戲迴圈、輸入、戰鬥、事件與存檔。
- `knowledge/`：願景、路線圖與開發經驗，不會發布到遊戲網站。

本專案使用原生 HTML、CSS、JavaScript 與 Canvas，沒有建置步驟；檔案可直接預覽，GitHub Pages 也能部署原始靜態資源。

## GitHub Pages

推送到 `main` 或 `master` 分支後，GitHub Actions 會自動將 `index.html` 發布到 GitHub Pages。網站工作流程只會發布遊戲頁面，不會發布 `knowledge/` 規劃文件。
